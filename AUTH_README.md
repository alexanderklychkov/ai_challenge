# Система авторизации AI Mentor

## Описание

Реализована полная система регистрации и авторизации пользователей для приложения AI Mentor.

## Возможности

- ✅ Регистрация новых пользователей
- ✅ Авторизация существующих пользователей
- ✅ JWT токены для безопасной аутентификации
- ✅ Хеширование паролей с помощью bcrypt
- ✅ Защита API роутов
- ✅ Защита фронтенд роутов
- ✅ Привязка чатов к пользователям

## Структура

### Backend

- `server/utils/userStorage.js` - Утилита для работы с пользователями (хранение в JSON)
- `server/auth/authController.js` - Контроллеры для регистрации и авторизации
- `server/auth/middleware.js` - Middleware для проверки JWT токенов
- `server/utils/chatStorage.js` - Обновлен для поддержки userId

### Frontend

- `src/services/auth.ts` - Сервис для работы с API авторизации
- `src/contexts/AuthContext.tsx` - React контекст для управления состоянием авторизации
- `src/pages/LoginPage.tsx` - Страница входа
- `src/pages/RegisterPage.tsx` - Страница регистрации
- `src/components/ProtectedRoute.tsx` - Компонент для защиты роутов
- `src/services/storage.ts` - Обновлен для использования токенов авторизации

## API Endpoints

### Регистрация
```
POST /api/auth/register
Body: {
  "email": "user@example.com",
  "password": "password123",
  "name": "Имя пользователя"
}
```

### Авторизация
```
POST /api/auth/login
Body: {
  "email": "user@example.com",
  "password": "password123"
}
```

### Получение информации о текущем пользователе
```
GET /api/auth/me
Headers: {
  "Authorization": "Bearer <token>"
}
```

## Настройка

### Переменные окружения

Добавьте в `.env` файл:

```env
JWT_SECRET=your-secret-key-change-in-production
JWT_EXPIRES_IN=7d
```

**Важно:** В продакшене обязательно используйте надежный секретный ключ!

## Использование

### Регистрация

1. Пользователь переходит на `/register`
2. Заполняет форму (имя, email, пароль)
3. После успешной регистрации автоматически авторизуется и перенаправляется в чат

### Авторизация

1. Пользователь переходит на `/login`
2. Вводит email и пароль
3. После успешной авторизации перенаправляется в чат

### Защита роутов

Все защищенные роуты автоматически проверяют наличие токена. Если токена нет, пользователь перенаправляется на страницу входа.

## Хранение данных

Пользователи хранятся в `server/data/auth/users.json`. Пароли хранятся в виде хешей (bcrypt).

## Безопасность

- Пароли хешируются с помощью bcrypt (10 раундов)
- JWT токены используются для аутентификации
- Токены имеют срок действия (по умолчанию 7 дней)
- Все защищенные API роуты проверяют токен
- Чаты привязаны к пользователям и изолированы

## Примечания

- При первом запуске создается директория `server/data/auth/`
- Файл `users.json` создается автоматически при первом создании пользователя
- Токен хранится в localStorage браузера
- При выходе токен удаляется из localStorage
