# Инструкция по использованию инструмента для работы со статьями

## Описание

Новый MCP инструмент `readArticle` позволяет AI читать статьи по URL и автоматически создавать задачи на основе их содержимого.

## Как использовать

### Шаг 1: Отправьте запрос с ссылкой на статью

Просто отправьте в чат сообщение с URL статьи, например:

```
Изучи эту статью и создай задачи для изучения: https://react.dev/reference/react/useEffect
```

или

```
Прочитай статью https://react.dev/reference/react/useEffect и создай несколько задач на основе её содержимого
```

### Шаг 2: AI автоматически выполнит цепочку действий

AI выполнит следующую цепочку:

1. **Чтение статьи** (`readArticle`) - извлекает содержимое статьи по URL
2. **Анализ содержимого** - AI анализирует прочитанную статью
3. **Создание задач** (`createTask`) - AI создает несколько релевантных задач для изучения материала
4. **Отображение сводки** - AI отправляет сводку по созданным задачам в чат

### Шаг 3: Проверьте результат

После выполнения вы увидите:

1. **Ответ AI** с анализом статьи и сводкой по созданным задачам
2. **Блок "Использованные инструменты MCP"** с информацией о:
   - `readArticle` - чтение статьи
   - `createTask` - создание каждой задачи (может быть несколько вызовов)

## Примеры использования

### Пример 1: Статья про React useEffect

```
Изучи статью https://react.dev/reference/react/useEffect и создай задачи для изучения
```

AI создаст задачи типа:
- "Изучить синтаксис useEffect"
- "Практиковать использование useEffect с зависимостями"
- "Разобрать примеры cleanup функций"

### Пример 2: Статья про TypeScript

```
Прочитай https://www.typescriptlang.org/docs/handbook/typescript-in-5-minutes.html и создай план изучения
```

### Пример 3: Статья с Medium или Dev.to

```
Изучи эту статью и создай задачи: https://dev.to/author/article-name
```

## Поддерживаемые платформы

Инструмент работает с большинством веб-сайтов:
- ✅ React документация (react.dev)
- ✅ MDN Web Docs
- ✅ Medium
- ✅ Dev.to
- ✅ Личные блоги
- ✅ Другие сайты с HTML контентом

## Ограничения

- Максимальный размер статьи: 50,000 символов (остальное обрезается)
- Некоторые сайты могут блокировать запросы (CORS)
- Для работы требуется доступ к интернету
- Инструмент извлекает только текст, изображения и код не сохраняются

## Технические детали

### Используемые инструменты

1. **readArticle** - читает статью по URL и извлекает текст
2. **createTask** - создает задачи в Todoist (вызывается несколько раз)

### Автоматическая цепочка

Агент автоматически определяет наличие URL в запросе и создает цепочку:
```
readArticle → анализ → createTask (×N) → сводка
```

## Устранение неполадок

### Статья не читается

- Проверьте, что URL корректен и доступен
- Убедитесь, что сайт не блокирует запросы
- Попробуйте другой URL

### Задачи не создаются

- Убедитесь, что `TODOIST_API_KEY` установлен
- Проверьте, что MCP включен в настройках чата
- Попробуйте более явный запрос: "Создай задачи на основе этой статьи"

### Ошибка извлечения текста

- Некоторые сайты используют сложную структуру HTML
- Попробуйте другую статью или платформу
- Инструмент работает лучше с простыми HTML страницами
