# Настройка Ollama в AIMentor

## Что было настроено

### 1. Расширенные параметры модели

Теперь поддерживаются все основные параметры Ollama:

- **temperature** (0.0-1.0) - Креативность ответов (по умолчанию: 0.7)
- **maxTokens** / **num_predict** - Максимальное количество токенов в ответе (по умолчанию: 2000)
- **numCtx** / **context_window** - Размер контекстного окна (по умолчанию: 2048)
- **topP** (0.0-1.0) - Top-p sampling (по умолчанию: 0.9)
- **topK** - Top-k sampling (по умолчанию: 40)
- **repeatPenalty** - Штраф за повторения (по умолчанию: 1.1)

### 2. Prompt-шаблоны для фокусировки на конкретной задаче

Создан специальный промпт, который заставляет модель отвечать **ТОЛЬКО на конкретный вопрос**, не отклоняясь от темы.

**Автоматически применяется промпт `focused`**, который:
- Заставляет отвечать только на заданный вопрос
- Запрещает добавлять лишнюю информацию
- Требует краткости и точности
- Позволяет задать только один уточняющий вопрос при неясности

### 3. Доступные промпт-шаблоны

В `src/utils/ollamaPrompts.ts` доступны следующие шаблоны:

- **focused** (по умолчанию) - Максимальная фокусировка на конкретной задаче
- **programming** - Для вопросов по программированию
- **learning** - Для обучения и объяснений
- **analysis** - Для анализа данных
- **default** - Базовый промпт с фокусировкой

## Использование

### Через настройки чата (UI)

1. Откройте настройки чата
2. Выберите или создайте агента типа "Ollama"
3. Настройте параметры:
   - **Модель**: выберите из списка или введите свою
   - **Температура**: 0.0-1.0 (рекомендуется 0.3-0.7)
   - **Max Tokens**: максимальная длина ответа

### Программно

```typescript
import { createOllamaModel } from './services/ollama';
import { getOllamaPrompt } from './utils/ollamaPrompts';

// Базовое использование (с промптом focused по умолчанию)
const model = createOllamaModel({
  model: 'qwen2.5:0.5b',
  temperature: 0.5,
  maxTokens: 2000,
});

// С кастомным промптом
const modelWithCustomPrompt = createOllamaModel({
  model: 'qwen2.5:0.5b',
  temperature: 0.7,
  maxTokens: 2000,
  systemPrompt: getOllamaPrompt('programming'),
});

// С дополнительными параметрами
const modelAdvanced = createOllamaModel({
  model: 'qwen2.5:0.5b',
  temperature: 0.5,
  maxTokens: 2000,
  numCtx: 4096,        // Увеличенное контекстное окно
  topP: 0.9,
  topK: 40,
  repeatPenalty: 1.1,
  systemPrompt: getOllamaPrompt('focused'),
});
```

## Как работает промпт focused

Промпт `focused` настроен так, чтобы модель:

1. **Отвечала ТОЛЬКО на заданный вопрос**
   - Не добавляет дополнительную информацию
   - Не переходит на другие темы
   - Не начинает рассказывать о смежных концепциях

2. **Была краткой и точной**
   - Убирает вводные фразы типа "Конечно!", "Рад помочь!"
   - Сразу переходит к ответу
   - Использует структуру только если это помогает

3. **Задавала вопросы только при необходимости**
   - Только один уточняющий вопрос
   - Только если вопрос действительно неясен

4. **Честно признавала незнание**
   - Не придумывает ответы
   - Говорит "не знаю" если не знает

## Технические детали

### Серверная часть (`server/handlers/ollama.js`)

Обработчик теперь принимает и передает все параметры Ollama:

```javascript
{
  temperature,
  max_tokens,
  num_ctx,
  context_window,
  top_p,
  top_k,
  repeat_penalty,
}
```

### Клиентская часть (`src/services/ollama.ts`)

- Автоматически применяет промпт `focused` если не указан другой
- Поддерживает все параметры Ollama через конфигурацию
- Передает параметры как через прокси, так и при прямом подключении

## Отладка

Если модель отклоняется от темы:

1. Проверьте, что промпт `focused` применяется (логи в консоли)
2. Уменьшите `temperature` до 0.3-0.4
3. Увеличьте `repeatPenalty` до 1.2-1.3
4. Убедитесь, что `systemPrompt` передается правильно

## Дополнительные настройки

Для еще большей точности можно:

1. Использовать более крупную модель (если позволяет память)
2. Увеличить `numCtx` для большего контекста
3. Настроить кастомный промпт под конкретную задачу
