# Todoist MCP Server - Инструменты

Этот MCP сервер предоставляет полный набор инструментов для работы с Todoist API.

## Структура проекта

```
server/mcp/
├── index.js           # Главный файл сервера
├── tools/
│   ├── tasks.js      # Инструменты для работы с задачами
│   ├── projects.js   # Инструменты для работы с проектами
│   ├── labels.js     # Инструменты для работы с метками
│   └── sections.js   # Инструменты для работы с секциями
└── README.md         # Этот файл
```

## Инструменты для работы с задачами

### `getTask`
Получить задачу по ID.

**Параметры:**
- `taskId` (string, обязательный) - ID задачи

### `getTasks`
Получить список всех задач с возможностью фильтрации.

**Параметры:**
- `projectId` (string, опционально) - ID проекта для фильтрации
- `sectionId` (string, опционально) - ID секции для фильтрации
- `label` (string, опционально) - Метка для фильтрации
- `limit` (number, опционально) - Максимальное количество задач

### `createTask`
Создать новую задачу.

**Параметры:**
- `content` (string, обязательный) - Текст задачи
- `description` (string, опционально) - Описание задачи
- `projectId` (string, опционально) - ID проекта
- `sectionId` (string, опционально) - ID секции
- `parentId` (string, опционально) - ID родительской задачи (для подзадач)
- `priority` (number, опционально) - Приоритет (1-4, где 4 - самый высокий)
- `labels` (array[string], опционально) - Массив меток
- `dueString` (string, опционально) - Срок в виде строки ("завтра", "2025-01-15")
- `dueDate` (string, опционально) - Срок в формате YYYY-MM-DD
- `dueDatetime` (string, опционально) - Срок с временем в формате ISO 8601

### `updateTask`
Обновить существующую задачу.

**Параметры:**
- `taskId` (string, обязательный) - ID задачи
- `content` (string, опционально) - Новый текст задачи
- `description` (string, опционально) - Новое описание
- `priority` (number, опционально) - Новый приоритет (1-4)
- `labels` (array[string], опционально) - Новый массив меток
- `dueString` (string, опционально) - Новый срок в виде строки
- `dueDate` (string, опционально) - Новый срок в формате YYYY-MM-DD
- `dueDatetime` (string, опционально) - Новый срок с временем

### `closeTask`
Закрыть (завершить) задачу.

**Параметры:**
- `taskId` (string, обязательный) - ID задачи

### `reopenTask`
Повторно открыть закрытую задачу.

**Параметры:**
- `taskId` (string, обязательный) - ID задачи

### `deleteTask`
Удалить задачу.

**Параметры:**
- `taskId` (string, обязательный) - ID задачи

### `searchTasks`
Поиск задач по фильтру (query string).

**Параметры:**
- `query` (string, обязательный) - Строка запроса ("today", "overdue", "@label")
- `lang` (string, опционально) - Язык для парсинга дат ("ru", "en")
- `limit` (number, опционально) - Максимальное количество результатов

### `moveTask`
Переместить задачу в другой проект, секцию или сделать подзадачей.

**Параметры:**
- `taskId` (string, обязательный) - ID задачи
- `projectId` (string, опционально) - ID проекта назначения (только один из projectId/sectionId/parentId)
- `sectionId` (string, опционально) - ID секции назначения
- `parentId` (string, опционально) - ID родительской задачи

## Инструменты для работы с проектами

### `getProject`
Получить проект по ID.

**Параметры:**
- `projectId` (string, обязательный) - ID проекта

### `getProjects`
Получить список всех проектов.

**Параметры:**
- `limit` (number, опционально) - Максимальное количество проектов

### `createProject`
Создать новый проект.

**Параметры:**
- `name` (string, обязательный) - Название проекта
- `parentId` (string, опционально) - ID родительского проекта (для подпроектов)
- `color` (string, опционально) - Цвет проекта ("berry_red", "red", "orange")
- `isFavorite` (boolean, опционально) - Добавить в избранное
- `viewStyle` (enum, опционально) - Стиль отображения ("list" или "board")

### `updateProject`
Обновить существующий проект.

**Параметры:**
- `projectId` (string, обязательный) - ID проекта
- `name` (string, опционально) - Новое название
- `color` (string, опционально) - Новый цвет
- `isFavorite` (boolean, опционально) - Добавить/убрать из избранного
- `viewStyle` (enum, опционально) - Новый стиль отображения

### `getArchivedProjects`
Получить список архивных проектов.

**Параметры:**
- `limit` (number, опционально) - Максимальное количество проектов

## Примеры использования

### Создать задачу с приоритетом и сроком
```
createTask({
  content: "Подготовить презентацию",
  priority: 4,
  dueString: "завтра",
  labels: ["важное", "работа"]
})
```

### Найти просроченные задачи
```
searchTasks({
  query: "overdue"
})
```

### Создать проект и добавить в него задачу
```
1. createProject({ name: "Новый проект", viewStyle: "board" })
2. createTask({ content: "Первая задача", projectId: "<project_id>" })
```

### Получить все задачи из проекта
```
getTasks({ projectId: "<project_id>" })
```

## Требования

- Node.js установлен и доступен в PATH
- Файл `.env` в корне проекта с переменной `TODOIST_API_KEY`
- Все зависимости установлены (`npm install`)
