# Руководство по использованию LM Studio в офлайн режиме

## Описание

AIMentor поддерживает работу с локальной моделью LM Studio в офлайн режиме. Это означает, что даже если сервер AIMentor недоступен, вы можете использовать локальную модель напрямую через браузер.

## Настройка

### 1. Настройка LM Studio

1. **Запустите LM Studio** и загрузите модель (например, `mistralai/ministral-3-3b`)

2. **Запустите локальный сервер** в LM Studio:
   - Перейдите в раздел "Local Server"
   - Нажмите "Start Server"
   - Убедитесь, что сервер работает на порту 1234 (по умолчанию)

3. **Настройте CORS** (важно для прямого доступа из браузера):
   - В настройках сервера LM Studio включите CORS
   - Или используйте параметр `--cors` при запуске сервера
   - Альтернативно, можно использовать расширение браузера для обхода CORS (только для разработки)

### 2. Настройка переменных окружения (опционально)

Создайте файл `.env` в корне проекта или настройте переменные окружения:

```env
# URL для прямого подключения к LM Studio (для офлайн режима)
VITE_LM_STUDIO_DIRECT_URL=http://localhost:1234/v1

# Включить офлайн режим по умолчанию (true/false)
# Если true, система будет пытаться подключиться напрямую к LM Studio
VITE_LM_STUDIO_OFFLINE_MODE=true

# URL прокси-сервера (если хотите использовать через сервер)
VITE_LM_STUDIO_PROXY_URL=http://localhost:3001/api/lmstudio
```

### 3. Использование в коде

При создании модели LM Studio вы можете настроить офлайн режим:

```typescript
import { createLMStudioModel } from './services/lmStudio';

// Создание модели с офлайн режимом
const model = createLMStudioModel({
  model: 'mistralai/ministral-3-3b',
  enableOffline: true, // Включить офлайн режим
  directUrl: 'http://localhost:1234/v1', // Прямой URL к LM Studio
});
```

## Как это работает

1. **Обычный режим** (по умолчанию):
   - Система сначала пытается обратиться к серверу AIMentor (`/api/lmstudio`)
   - Если сервер недоступен (offline режим браузера или сетевые проблемы), система автоматически переключается на прямое подключение к LM Studio

2. **Офлайн режим** (`enableOffline: true`):
   - Система сразу обращается напрямую к LM Studio
   - Если прямое подключение не удалось, пробует через сервер как fallback

## Автоматический выбор модели

Если модель не указана или указано `__auto__`, система автоматически:
1. Запрашивает список доступных моделей из LM Studio
2. Выбирает первую chat-модель (не embedding)
3. Использует её для запросов

## Обработка ошибок

Система автоматически обрабатывает следующие ситуации:
- Сервер недоступен → переключение на прямое подключение
- LM Studio недоступен → показ понятного сообщения об ошибке
- Модель не загружена → автоматический выбор другой модели или сообщение об ошибке

## Ограничения

1. **CORS**: Для прямого доступа из браузера необходимо настроить CORS в LM Studio
2. **Безопасность**: Прямое подключение работает только для локальных адресов (localhost)
3. **Сохранение сообщений**: В офлайн режиме сохранение сообщений на сервер может не работать

## Отладка

Если возникают проблемы:

1. Проверьте, что LM Studio запущен и сервер активен
2. Проверьте URL в консоли браузера (F12)
3. Проверьте настройки CORS в LM Studio
4. Убедитесь, что модель загружена в LM Studio
5. Проверьте переменные окружения

## Примеры использования

### Базовое использование
```typescript
const model = createLMStudioModel({
  model: 'mistralai/ministral-3-3b',
});
```

### С автоматическим выбором модели
```typescript
const model = createLMStudioModel({
  model: '__auto__', // Автоматический выбор
});
```

### С принудительным офлайн режимом
```typescript
const model = createLMStudioModel({
  model: 'mistralai/ministral-3-3b',
  enableOffline: true,
  directUrl: 'http://localhost:1234/v1',
});
```
