# Dev Assistant CLI

Интегрированный командный ассистент для разработчиков с поддержкой RAG для документации проекта, MCP для работы с git-репозиторием и Todoist для управления задачами.

## Возможности

- 📚 **RAG для документации**: Использует RAG (Retrieval-Augmented Generation) для подключения к документации проекта (README, API, схемы данных)
- 🔧 **Git MCP**: Подключается к текущему git-репозиторию через MCP для понимания текущей ветки и открытых файлов
- ✅ **Todoist интеграция**: Работа с задачами через Todoist API - создание, поиск, обновление задач, анализ приоритетов
- 💡 **Умные рекомендации**: Анализирует задачи и дает рекомендации по приоритетам, предлагает что делать первым
- 🎨 **Markdown в консоли**: Красивое форматирование markdown разметки в терминале с подсветкой синтаксиса кода, заголовков, списков и других элементов
- 🤖 **Автоматическое ревью PR**: Проводит автоматическое ревью Pull Request с использованием RAG и GitHub API (см. [PR_REVIEW_GUIDE.md](./PR_REVIEW_GUIDE.md))

## Установка

1. Установите зависимости:
```bash
cd cli-assistant
npm install
```

2. Настройте переменные окружения в `.env` файле в корне проекта:

```env
# Выберите один из провайдеров LLM
DEEPSEEK_API_KEY=your_deepseek_api_key
# или
OPENAI_API_KEY=your_openai_api_key
# или
YANDEX_API_KEY=your_yandex_api_key
YANDEX_FOLDER_ID=your_yandex_folder_id

# Для эмбеддингов (обязательно для работы RAG)
# Используется Hugging Face Inference Providers API
# Документация: https://huggingface.co/docs/inference-providers/index
HF_TOKEN=your_huggingface_token
# Получить токен: https://huggingface.co/settings/tokens
# Используется модель: sentence-transformers/all-MiniLM-L6-v2 (по умолчанию)

# Для работы с Todoist (опционально, но рекомендуется)
TODOIST_API_KEY=your_todoist_api_key
# Получить API ключ: https://todoist.com/app/settings/integrations/developer
```

## Использование

### Интерактивный режим

Запустите интерактивный режим:

```bash
node index.js start
# или просто
node index.js
```

В интерактивном режиме вы можете:
- Задать вопрос напрямую (без префикса `/help`)
- Использовать команду `/help <ваш вопрос>` для получения помощи по проекту
- Работать с задачами: "Покажи задачи с приоритетом high", "Создай задачу", "Что делать первым?"
- Использовать команду `/exit` для выхода

### Команда help

Задайте вопрос о проекте напрямую:

```bash
node index.js help "Как работает аутентификация в этом проекте?"
```

### Работа с задачами

Ассистент может работать с задачами через Todoist:

```bash
# Показать задачи с высоким приоритетом и предложить что делать первым
node index.js help "Покажи задачи с приоритетом high и предложи, что делать первым"

# Создать задачу
node index.js help "Создай задачу 'Исправить баг в авторизации' с приоритетом 4"

# Найти просроченные задачи
node index.js help "Покажи просроченные задачи"
```

### Индексация документации

Перед использованием ассистента необходимо проиндексировать документацию проекта:

```bash
node index.js index -d ./docs
```

Где `-d` или `--dir` - путь к директории с документацией (по умолчанию `./docs`).

Индекс сохраняется в `.dev-assistant/index.json` в корне проекта.

### Ревью Pull Request

Провести ревью PR:

```bash
node index.js review <PR_NUMBER>
```

Например:
```bash
node index.js review 42
```

Для автоматического ревью при создании PR настройте GitHub Actions workflow (см. [PR_REVIEW_GUIDE.md](./PR_REVIEW_GUIDE.md)).

## Как это работает

1. **RAG для документации**: 
   - Документация проекта индексируется с помощью эмбеддингов
   - При запросе пользователя система ищет релевантные фрагменты документации
   - Эти фрагменты используются как контекст для генерации ответа LLM

2. **Git MCP**:
   - Система автоматически определяет текущую ветку git
   - Отслеживает измененные файлы в рабочей директории
   - Эта информация используется как дополнительный контекст при ответах

3. **Todoist MCP**:
   - Интеграция с Todoist API для работы с задачами
   - Поддержка function calling для автоматического вызова инструментов
   - Анализ задач и рекомендации по приоритетам
   - Создание, поиск, обновление и закрытие задач

4. **Команда /help**:
   - Анализирует вопрос пользователя
   - Ищет релевантную информацию в документации через RAG
   - Учитывает текущий контекст git-репозитория
   - При необходимости использует инструменты Todoist для работы с задачами
   - Генерирует ответ с использованием LLM с поддержкой function calling

## Требования

- Node.js 18+
- Git (для работы с git-репозиторием)
- HF_TOKEN для Hugging Face Inference Providers API (обязательно для работы RAG)
- TODOIST_API_KEY для работы с задачами (опционально, но рекомендуется)

## Поддерживаемые форматы документов

- Markdown (`.md`, `.markdown`)
- Текстовые файлы (`.txt`)
- PDF (`.pdf`) - требует установки `pdf-parse`
- Код (`.js`, `.ts`, `.jsx`, `.tsx`, `.py`, `.java`, `.cpp`, `.c`, `.cs`, `.go`, `.rs`, `.rb`, `.php`, `.swift`, `.kt`, `.scala`, `.html`, `.css`, `.json`, `.xml`, `.yaml`, `.yml`)

## Примеры использования

```bash
# Индексация документации
node index.js index -d ./docs

# Задать вопрос в интерактивном режиме
node index.js start
> /help Как работает система аутентификации?

# Задать вопрос напрямую
node index.js help "Где находится код для обработки API запросов?"

# Работа с задачами
node index.js help "Покажи задачи с приоритетом high и предложи, что делать первым"
node index.js help "Создай задачу 'Рефакторинг модуля авторизации' с приоритетом 4"
node index.js help "Покажи просроченные задачи"

# Провести ревью PR
node index.js review 42
```

## Примечания

- Индекс документации сохраняется локально в `.dev-assistant/index.json`
- Система автоматически определяет git-репозиторий в текущей директории
- Если git-репозиторий не найден, некоторые функции могут быть недоступны
- Для работы с задачами требуется настроить TODOIST_API_KEY
- Ассистент использует function calling для автоматического вызова инструментов Todoist при необходимости
- Поддержка function calling доступна для OpenAI и DeepSeek API; YandexGPT использует текстовое описание инструментов
