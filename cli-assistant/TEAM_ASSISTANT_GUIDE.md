# Руководство по использованию командного ассистента

Интегрированный ассистент команды, который объединяет знание проекта (RAG), работу с git и управление задачами через Todoist.

## Быстрый старт

1. Установите зависимости:
```bash
cd cli-assistant
npm install
```

2. Настройте переменные окружения в `.env`:
```env
# LLM провайдер (один из)
DEEPSEEK_API_KEY=your_key
# или
OPENAI_API_KEY=your_key

# Для RAG (обязательно)
HF_TOKEN=your_huggingface_token

# Для работы с задачами (рекомендуется)
TODOIST_API_KEY=your_todoist_api_key
```

3. Проиндексируйте документацию:
```bash
node index.js index -d ./docs
```

4. Запустите ассистента:
```bash
node index.js start
```

## Примеры использования

### Работа с задачами

#### Показать задачи с высоким приоритетом и получить рекомендации
```
> Покажи задачи с приоритетом high и предложи, что делать первым
```

Ассистент:
- Найдет все задачи с приоритетом 4 (high)
- Проанализирует их сроки и описания
- Предложит порядок выполнения на основе приоритетов и сроков

#### Создать задачу
```
> Создай задачу "Исправить баг в авторизации" с приоритетом 4
```

#### Найти просроченные задачи
```
> Покажи просроченные задачи
```

#### Поиск задач по фильтру
```
> Покажи задачи с меткой "bug"
> Покажи задачи на сегодня
> Покажи задачи из проекта "Frontend"
```

### Вопросы о проекте

#### О структуре проекта
```
> Как работает система аутентификации?
> Где находится код для обработки API запросов?
> Какие есть эндпоинты для работы с пользователями?
```

#### О текущем статусе
```
> Какие файлы изменены в текущей ветке?
> Что изменилось в последнем коммите?
```

### Комбинированные запросы

Ассистент может комбинировать информацию из разных источников:

```
> Покажи задачи с приоритетом high и объясни, как они связаны с текущими изменениями в git
```

## Возможности

### RAG (Retrieval-Augmented Generation)
- Поиск информации в документации проекта
- Контекстные ответы на основе индексированных документов
- Поддержка различных форматов (Markdown, код, PDF)

### Git MCP
- Автоматическое определение текущей ветки
- Отслеживание измененных файлов
- Контекст для ответов на основе текущего состояния репозитория

### Todoist интеграция
- Создание задач
- Поиск и фильтрация задач
- Обновление задач (приоритет, сроки, метки)
- Закрытие задач
- Анализ приоритетов и рекомендации

### Function Calling
- Автоматический вызов инструментов при необходимости
- Интеллектуальная обработка запросов
- Многошаговые операции (поиск → анализ → рекомендации)

## Советы по использованию

1. **Конкретные запросы**: Чем конкретнее вопрос, тем точнее ответ
   - ✅ "Покажи задачи с приоритетом 4 и предложи порядок выполнения"
   - ❌ "Что делать?"

2. **Комбинирование**: Используйте комбинации для более сложных запросов
   - "Покажи задачи из проекта X и объясни, как они связаны с текущими изменениями"

3. **Приоритеты**: Ассистент понимает приоритеты Todoist (1-4, где 4 - самый высокий)
   - "high" = 4
   - "medium" = 2-3
   - "low" = 1

4. **Фильтры**: Используйте фильтры Todoist для точного поиска
   - "priority 4" - высокий приоритет
   - "today" - задачи на сегодня
   - "overdue" - просроченные задачи
   - "@label" - задачи с меткой

## Устранение неполадок

### Todoist API не работает
- Проверьте, что `TODOIST_API_KEY` установлен в `.env`
- Убедитесь, что ключ действителен (получить можно здесь: https://todoist.com/app/settings/integrations/developer)

### Function calling не работает
- Убедитесь, что используете OpenAI или DeepSeek API (YandexGPT не поддерживает function calling напрямую)
- Проверьте, что модель поддерживает function calling (gpt-3.5-turbo, gpt-4, deepseek-chat)

### RAG не находит информацию
- Убедитесь, что документация проиндексирована: `node index.js index -d ./docs`
- Проверьте, что `HF_TOKEN` установлен для эмбеддингов
