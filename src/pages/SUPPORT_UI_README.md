# Интерфейс поддержки пользователей

## Описание

Интерфейс поддержки интегрирован в основное приложение AI Mentor и предоставляет удобный способ взаимодействия с AI ассистентом поддержки.

## Доступ

Интерфейс доступен через:
- Маршрут: `/support`
- Кнопка "Поддержка" в переключателе режимов (рядом с "Чат" и "Обучение")

## Возможности

### 1. Чат с поддержкой
- Задавайте вопросы в текстовом поле
- Получайте ответы с учетом контекста ваших тикетов и документации
- История сообщений сохраняется в сессии

### 2. Контекстная информация
- **Email пользователя**: Укажите ваш email для получения информации о ваших тикетах
- **ID тикета**: Укажите ID тикета для работы с конкретной проблемой

### 3. Боковая панель
Отображает контекстную информацию:
- Информация о пользователе (если найден)
- Информация о текущем тикете (если указан)
- Похожие решенные проблемы
- Источники из документации (RAG чанки)

## Использование

### Базовое использование

1. Откройте раздел "Поддержка"
2. Введите ваш вопрос в поле ввода
3. Нажмите кнопку отправки или Enter
4. Получите ответ с учетом контекста

### С указанием email

1. Введите ваш email в поле "Email (опционально)"
2. Задайте вопрос
3. Система автоматически найдет ваши тикеты и использует их как контекст

### С указанием тикета

1. Введите ID тикета в поле "ID тикета (опционально)"
2. Задайте вопрос о тикете
3. Система загрузит историю тикета и использует её для ответа

## Примеры вопросов

- "Почему не работает авторизация?"
- "Как перейти на премиум тариф?"
- "Что с тикетом ticket-1?"
- "Не могу загрузить файл размером 5MB"

## Технические детали

### Компоненты

- `SupportPage.tsx` - основная страница поддержки
- `support.ts` - сервис для работы с API поддержки

### API Endpoint

Используется `/api/support/query` для отправки запросов.

### Интеграция

- RAG для поиска в документации
- MCP для работы с CRM (тикеты и пользователи)
- Поддержка всех LLM моделей (DeepSeek, YandexGPT, ChatGPT, HuggingFace)

## Стилизация

Интерфейс использует тот же дизайн, что и остальное приложение:
- Темная тема с градиентами
- Адаптивный дизайн
- Анимации и переходы
- Подсветка источников и метаданных
