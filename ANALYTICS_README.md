# Локальный аналитик данных

Локальный аналитик данных позволяет анализировать CSV, JSON и лог-файлы с помощью локальных LLM моделей (Ollama или LM Studio) без отправки данных в облако.

## Возможности

- ✅ Загрузка файлов CSV, JSON и LOG
- ✅ Автоматический парсинг и анализ структуры данных
- ✅ Анализ данных с помощью локальных LLM (Ollama/LM Studio)
- ✅ Ответы на аналитические вопросы на русском языке
- ✅ Полная приватность - все данные обрабатываются локально

## Использование

### 1. Загрузка данных

1. Перейдите на страницу "Аналитик" в боковом меню
2. Загрузите файл данных (CSV, JSON или LOG)
   - Можно перетащить файл или выбрать через диалог
3. После загрузки вы увидите сводку данных:
   - Количество записей
   - Список колонок и их типы
   - Для логов: статистика по ошибкам и уровням логирования

### 2. Настройка модели

Выберите тип модели:
- **Ollama** - рекомендуется для локального использования
- **LM Studio** - альтернативный вариант

Опционально укажите конкретную модель (если оставить пустым, будет использована модель по умолчанию).

### 3. Анализ данных

Задайте вопрос о данных, например:
- "Какая ошибка встречается чаще всего?"
- "Сколько всего записей в данных?"
- "Какие колонки есть в данных?"
- "Где больше всего пользователей теряется?"
- "Покажи статистику по ошибкам"

Модель проанализирует данные и даст подробный ответ на русском языке.

## Поддерживаемые форматы

### CSV
- Разделители: запятая (`,`) или точка с запятой (`;`)
- Автоматическое определение типов колонок
- Поддержка кавычек в значениях

### JSON
- Массивы объектов
- Отдельные объекты
- Автоматическое определение структуры

### LOG
- Автоматическое извлечение:
  - Timestamp
  - Уровень логирования (ERROR, WARN, INFO, DEBUG, etc.)
  - Сообщения
  - Типы ошибок
- Статистика по ошибкам и уровням

## API Endpoints

### POST `/api/analytics/upload`
Загружает и парсит файл данных.

**Request:**
```json
{
  "fileData": "base64_encoded_file_data",
  "fileName": "data.csv"
}
```

**Response:**
```json
{
  "success": true,
  "data": [...],
  "summary": {
    "totalRows": 100,
    "columns": [...]
  },
  "type": "csv",
  "fileName": "data.csv"
}
```

### POST `/api/analytics/analyze`
Анализирует данные с помощью LLM.

**Request:**
```json
{
  "data": [...],
  "summary": {...},
  "question": "Какая ошибка встречается чаще всего?",
  "modelType": "ollama",
  "model": "qwen2.5:0.5b",
  "temperature": 0.3,
  "maxTokens": 4000
}
```

**Response:**
```json
{
  "success": true,
  "answer": "Ответ модели..."
}
```

### POST `/api/analytics/stats`
Получает быструю статистику по данным.

**Request:**
```json
{
  "data": [...],
  "summary": {...}
}
```

**Response:**
```json
{
  "success": true,
  "stats": {
    "totalRows": 100,
    "columns": [...],
    "numericStats": {...}
  }
}
```

## Требования

- Локальная LLM модель (Ollama или LM Studio)
- Авторизация в системе

## Безопасность

- Все данные обрабатываются локально
- Файлы сохраняются во временной директории на сервере
- Никакие данные не отправляются в облако
- Требуется авторизация для доступа к API
